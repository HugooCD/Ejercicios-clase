Tarea 3 — Preguntas y respuestas

Pregunta 1: ¿Qué es HTML?

Respuesta 1: HTML (HyperText Markup Language) es el lenguaje de marcado estándar para crear páginas web y su estructura.

Pregunta 2: ¿Para qué sirve CSS?

Respuesta 2: CSS (Cascading Style Sheets) se utiliza para describir la presentación de documentos HTML, gestionando colores, fuentes, espacios y disposición.

Pregunta 3: ¿Qué es la accesibilidad web?

Respuesta 3: La accesibilidad web busca que las páginas sean utilizables por el mayor número de personas posible, incluyendo personas con discapacidades; implica buenas prácticas de marcado, contraste y navegación.
